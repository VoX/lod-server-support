# Installation and first connection

Choose the exact Minecraft line and loader in the [compatibility catalog](../compatibility.md). Its build, shipping, renderer and optional-integration facts are separate: a shipped jar does not establish that an arbitrary Voxy, Xaero, Sodium or Connector combination works. Match optional components to the line's reviewed profiles under `config/compatibility/profiles/`; installed or blocked profiles are not live certification. Minecraft 1.21.x uses Java 21; 26.x uses Java 25. The 26.1 support line targets Minecraft 26.1.2.

Install the matching LSS Fabric/NeoForge mod in the server's `mods` directory, or the Paper plugin in `plugins`. Install the matching client mod for every participating client, with a compatible LOD consumer. Voxy terrain and the optional Xaero map bridge are distinct consumer paths. Enabling persistent Xaero map writes is an explicit client choice. Consult the catalog before selecting NeoForge or Folia; Folia remains experimental, and absent platform rows cannot be supplied by another line's jar.

Start once to generate configuration. Fabric/NeoForge use `config/lss-server-config.json` and the client uses `config/lss-client-config.json`. Paper uses its plugin data directory, normally `plugins/LodServerSupport/lss-server-config.json`. VSS prefers the corresponding `vss-` filenames and its branded data directory; an existing adopted LSS/VSS file remains the active save target. Read the actual startup log and file instead of creating a second copy. Keep a backup before changing an established installation.

Join the server, run `/lss status`, then `/lss diag`. Look for negotiated service, reception ON and an available consumer. Operators can use `/lsslod help`, `/lsslod diag` and `/lsslod store status`. VSS command roots are `/vss` and `/vsslod`. A successful connection does not prove far-player rendering or map writes; check those features separately. See [troubleshooting](troubleshooting.md), [settings](../reference/settings.md), and [status and presets](status-and-presets.md) for the next step.
