## Validation and maintenance

Run exact-version common/Fabric/Paper/NeoForge builds and unit suites on all five lines, Fabric and NeoForge server gametests, and private-display Fabric client gametests on the four lines that support them. The new CommandGameTests regression executes world override set/clear through Brigadier, checks negotiation values and rejects a request one chunk beyond the override boundary. Retain Paper dimension-change and equal-distance/no-repush tests, legacy-dialect guards, dirty-broadcast limits, global sizing, persistence, presets and source/metadata checks.

Cross-line classification now makes identical world-distance core/settings/tests shared invariants; Minecraft-specific resolvers and service call sites remain exact-reviewed adaptations. Release publication remains LSS only, with the existing loader matrix and support tiers.

The first 1.21.10 validation exposed the previously reported generation-outcome test timeout. A controlled phase-4 delay reproduced a test ordering race; the same control passes after waiting for the injected failure to be consumed. The common test is corrected identically on all lines without production behavior changes or weaker assertions; see the flake catalog.
