# P1 / P7 normative implementation audit — 2026-09-09

This is an implementation audit against the amended project-improvements plan, not a substitute for its exact-artifact live and performance gates. All five worktrees carry the implementation. The conservative numeric server preset remains unavailable until reference measurements select and justify its values.

| Requirement | Implementation and protected behavior | Verification |
| --- | --- | --- |
| Complete settings inventory | Generated explicit Server/Client/Paper descriptors inventory every serialized field; runtime and Sodium control registries override control metadata. Unknown field types or missing domain classifications fail generation. No runtime reflection registry. | SettingMetadataTest, SettingInventoryTest; inventory.py --check on all five lines |
| Defaults, units, sentinels, adoption | Explicit domains retain AUTO disk limits, zero dirty-push disable, zero client rate unlimited, negative MiB adoption/defaults, new-install store ON versus upgraded missing-key OFF, legacy memory normalization to OFF, Paper resweep constructor default, far-player privacy defaults.
