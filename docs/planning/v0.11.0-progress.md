  broadcasts** — previously 0 clamped to 1 s, the fastest cadence. With 0, connected

  freshness bookkeeping still runs, so rejoins always see current terrain.

  concurrent expensive region reads so server CPU stays bounded independently of
  bandwidth; store-served LODs never consume its capacity (auto = half the reader
  pool with the store on, no limit with it off). Raise bandwidth freely on
  store-heavy servers.

  the disk-read concurrency gate headline (cold-region reads no longer turn a
