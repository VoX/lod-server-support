Prepared 2026-11-14. **Not merged, not tagged.** 26.1 and 1.21.10 are frozen at 0.21.x
([decision 0001](https://github.com/VoX/lod-server-support/blob/main/docs/decisions/0001-line-tiers.md)):
crash and security fixes only. 0.21.1 brings them the Fabric server crash fix that ships in
0.22.0 (main `92e4dd7a5`, PR #412). Identities, counts and jar hashes are in the
[manifest](../implementation/2026-11-14-v0.21.1-release-preparation.json). Notes:
`v0.21.1-release-notes/` (one file per line).

## Scope

- **The crash fix.** Fabric fires its DISCONNECT event from netty or the server thread,
  whichever comes first; the cleanup ran where the event fired and could crash the server
  (`ConcurrentModificationException` in `ChunkGenerationService.tick`) when a player was kicked
  or timed out with generations in flight. The event body now hands the cleanup to the server
  thread. The 0.22.0 record has the trace and the frequency. Applied from main's commit
  unchanged on both lines; on 1.21.10 the new gametest uses this line's assertion form
  (`Gt.assertTrue(helper, …)`, since `GameTestHelper.assertTrue` takes a `Component` there).
- **The line is marked frozen.** `line.json` carries `"role": "frozen"`; the old six-line
  `tools/compat/ci.py` says so and compares nothing; the catalog workflow no longer runs the
  comparison. README, CLAUDE.md and the support-lines page say the line is frozen.
- **No Sponge build.** Sponge ships from main only (decision 0001), as the maintained lines did
  for 0.22.0: `LINE_SHIP_SPONGE=false` with the `release_check.py` mirror, `line.json` and the
  workflow contract pin. 0.21.0 stays published for Sponge. Paper and NeoForge (26.1) are
  rebuilt unchanged and ship as 0.21.1 so each line keeps one current version; the notes say
  only Fabric servers need the update.
- **No beta.** Decision 0002 lets a crash fix skip the soak; the notes say so.
