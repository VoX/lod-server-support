## Scope

[Plan](2026-11-13-v0.23.0-plan.md): two reviewers before any code (§9) and two on the finished
diff (§10).

- **A settings mistake is impossible to miss** (§1). A file with a mistake still does not load
  ([decision 0009](../decisions/0009-settings-stay-strict.md)); the refusal now lists every
  problem with its line and, for a near miss, the name that was meant. Server: console at
  startup and again after it, `/lsslod`, and one chat line to each player who may run it.
  Client: a status verdict ahead of every other one and one chat line per game start.
  `yes`/`no`/`on`/`off` are accepted for switches, in both client files.
- **"Share My Position: off" always reaches the server** (§2). It is sent at join, session or
  not; "on" still waits for a session. The server's diagnostics count kept opt-outs
  (`opted_out=`).
- **Which "switched off"** (§3). A disabled session answer carries one reason bit (server, world,
  permission) where the frame already has a flags field. Four verdicts and notices on the client.
- **`/lss` on the VSS client** (§4, [decision 0005](../decisions/0005-command-roots.md)): the
  extra name steps aside while the server has a command of that name.
- **Voxy says when it is not drawing** (§6a): two verdicts from Voxy's own answer, in place of
  "Working".
- From the 0.22.0 visual pass: the status details say "unknown" for a backlog nobody reports,
  and the option label Sodium cut off is now "Extend Draw Range".
- Real-stack tool (§5): Paper servers and a Paper row, a server-settings hook, a client-settings
  hook, and the scenarios `off-in-world` and `client-receives-nothing`.

Built in the conservative form, waiting for VoX:

- **`service.show_permission_refusal` is off by default.** With `require_permission` on, a
  refused player reads the general "switched off here" as in 0.22; the operator can switch the
  permission reason on. The proposal is on by default.
- **"Share My Position: on" is not sent without a session.** On an `opt_in` server it would show
  players who are hidden today.

Decided against, with reasons in the plan (§6): ignoring unknown settings, VSS server command
aliases, a server answer to unknown protocol versions, a server chat line for refused players.

Each rule has a test that one deliberate break turns red: 49 for the four features, 14 for the
Voxy verdict and the visual-pass items, 16 for the review fold. One was equivalent (a guard that
cannot be reached) and is recorded with its spec.

One red on the way was not the mod: a store unit test timed out once in a combined run. A race in
the test rig's `admit`, reproduced with a pause, fixed and written up in
[the flake catalog](../operations/test-flakes.md).
