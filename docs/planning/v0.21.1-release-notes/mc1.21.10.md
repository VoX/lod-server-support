### Bug Fixes

- **Fabric server crash** — A Fabric server could crash when a player was kicked or timed out while distant terrain was still being generated for them. Only Fabric servers need this update. It is the same fix as in 0.22.0 and did not go through a beta test.

### Support

- **Platforms** — Fabric and Paper/Purpur for Minecraft 1.21.10.
- **Frozen version line** — Minecraft 1.21.10 now gets crash and security fixes only. New features ship for Minecraft 26.3, 26.2, 1.21.11 and 1.21.1.
- **Sponge** — There is no 0.21.1 for Sponge: Sponge builds are made for the newest Minecraft version only. 0.21.0 stays available for Sponge on 1.21.10.
