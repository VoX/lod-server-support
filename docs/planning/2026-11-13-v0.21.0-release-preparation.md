# LSS 0.21.0 release preparation

Prepared 2026-11-13 on all six lines. Identities, counts and jar hashes are in the
[manifest](../implementation/2026-11-13-v0.21.0-release-preparation.json). Notes:
`v0.21.0-release-notes/` (one file per line).

## Scope

- **Far-player hide permission** ([plan](2026-11-12-far-player-hidden-permission-plan.md), VoX's
  decision): `lss.farplayers.hidden` hides nobody by itself (a wildcard grant such as LuckPerms `*`
  used to hide every admin); `far_players.hide_permission_holders` (default off) restores forced
  hiding; new `far_players.mode: required` ignores opt-outs except for holders. Players whose choice
  is overridden, and holders on a server that has not set the new key, are told in chat once per
  connection. The client status shows how many far players the server sends.
- **Black distant terrain** ([plan](2026-11-12-lightless-chunks-sky-light-plan.md), #382 class and
  #383): the client estimates sky light for a column that arrives without any, by vanilla's rule
  inside the column; the Distant Horizons adapter carries light through tree crowns
  (`CONVERSION_VERSION` 7, that terrain downloads once again). The server counts `lightless=`.
- **Undecodable chunks** ([plan](2026-11-12-undecodable-chunks-plan.md)): a chunk whose used block
  entries all fail to decode is never sent or stored as air and never loaded by LSS (`unservable`,
  `undecodable=`).
- **Re-download Terrain** ([plan](2026-11-12-redownload-terrain-button-plan.md)): a button on the
  mod's Sodium 0.8+ page with a confirm dialog; `/lss clearcache` follows the connection (never
  every server while connected to a remote one). 1.21.10 has no Sodium 0.8, so no button there.
- **Fixes**: Escape through the key event on the status and save screens (a real bug on 26.3, where
  Escape is 41); the Via refusal log line no longer says "the client must update"; a held want-set
  batch is paired with its own offer generation (latent since 0.15.0); the Distant Horizons stopped
  notice names the brand's own command.
- **Tests**: the corrupt-region gametest stages its file where 26.x reads it (it tested nothing on
  26.1 to 26.3); one Mockito mock maker in the Fabric test JVM (an order-dependent 19-test red);
  `SqliteLodStoreTest.tombstonesOutliveTheirOwnQueuedDeletes` waits for the step it inspects.

Reviews: each plan by two reviewers (correctness, decisions critic) before implementation; the
implementation on main by four (far-player privacy, terrain data, client UI, decisions and ports);
every finding folded or dispositioned in the plans. Each port proved its tests with one deliberate
break per item.

## Live (private displays, disposable local rigs, no accounts)

- **Real Sodium**: the Re-download Terrain row, all three dialog variants, Escape press and
  release, staged changes surviving, the toast and the server re-send on 26.3 Fabric (0.9.2) and
  NeoForge (0.9.2 on 26.3.0.1-beta, 0.9.3-beta.1 on 26.3.0.76), 26.2 (0.9.1-beta.3), 26.1 (0.8.12)
  and 1.21.1 Fabric and NeoForge (0.8.13-beta.2). Legacy Sodium 0.6.13 (1.21.1) and 0.7.3 (1.21.10)
  pages are pixel-identical to 0.20.0, with no row.
- **Far players**, Paper 26.3 + LuckPerms 5.5.71, two production clients: a `*` holder is shown by
  default, one WARN per start, the holder line once per connection until the key is written;
  `hide_permission_holders: true` hides; `required` shows an opted-out non-holder and tells them
  once (also a 0.20.0 client, in English), keeps an opted-out holder hidden, and follows a reload
  and a revoked permission.
- **Undecodable chunk** with the store on, Fabric and Paper: one WARN, `undecodable=1`, no store
  row, no generation, the region file byte-identical afterwards, the client gets no air column.
- **Lightless world**: 26.3 with Voxy, the stripped world looks like the lit one (under 0.4 % of
  pixels noticeably darker, under leaf crowns and on a few steps; no holes or border seams), a
  0.20.0 client shows it black; the same on NeoForge 1.21.1, with `lightless=` on the server.
- **Distant Horizons tree crowns** on the reporter's stack (NeoForge 1.21.1, sodium-neoforge 0.8.13,
  Roxy 0.4.1, Voxy 0.2.16-beta, Motschen's Better Leaves, DH 3.3.3 server): 13 to 16 % of the far
  band pure black with 0.20.0, 0.0 to 0.1 % with the candidate; identical without the pack; the
  terrain downloads once after the update.
(Taken on the content heads before the final pin; later commits changed tests, docs, the version
and one notice argument, all covered by the gates above.)

## Known, not from this release

- sodium-neoforge 0.9.2 itself crashes on NeoForge 26.3.0.76 (0.9.3-beta.1 works).
- After the dialog closes, Sodium shows its own first page, not the mod's page (cosmetic).
- 1.21.10 legacy page: in a narrow window the tab arrows can do nothing (hidden tabs take the
  click, since Minecraft 1.21.9); every page is reachable by its tab. Also in 0.20.0.
- Issue #382's own world (NeoForge 1.21.1, C2ME, ScalableLux, Chunky) reproduced lit; the reporter's
  cause is unknown. The client-side estimate covers it if their server sends terrain without sky
  light.
